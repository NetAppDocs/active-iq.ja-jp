= Digital Advisorでストレージ システムのリスク履歴を表示する
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
過去 3 か月間に発生したストレージ システムのリスクを表示して、時間の経過とともにどのように推移しているかを把握できます。

これらのリスクは、「 * 未解決 * 」、「新規 * 」、「解決済み * 」、「承認済み * 」の 4 種類のリスクに分類されます。これらは異なる色で表されます。これらのリスクの概要は、リスク履歴 * グラフで表されます。

.手順
. ダッシュボードの「ウェルネス」ペインで、「すべてのアクションを表示」を選択します。
. 「Wellness History」を選択してください。
. 「リスク履歴」グラフで、リスク履歴を表示するカテゴリを選択します。
+
色付きの棒グラフにカーソルを合わせると、各カテゴリのリスク数に関する情報が表示されます。該当するリスクカテゴリを選択すると、その情報が「リスク情報」テーブルに表示されます。

+
Excel シートにリスクの概要をダウンロードすることもできます。
